# 📝 To-Do App

A simple and responsive To-Do List web application built using **HTML**, **CSS**, and **JavaScript**. It allows users to manage daily tasks by adding, completing, and deleting them.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 🎨 Clean and responsive user interface
- ⚡ Fast and lightweight

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
